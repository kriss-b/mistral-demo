# Security Feeds Register

This register tracks the security intelligence feeds and communities the organization subscribes to, in support of [A.5.6 — Contact with special interest groups](../../policies/isms_policy.md). Actions taken based on feed intelligence are recorded in [threat_intel_log.md](../logs/threat_intel_log.md).

| Feed | Category | URL |
|------|----------|-----|
| CERT-FR (French national CERT, ANSSI) | Government | https://www.cert.ssi.gouv.fr/ |
| ENISA (EU Agency for Cybersecurity) | Government | https://www.enisa.europa.eu/ |
| CISA KEV (Known Exploited Vulnerabilities) | Government | https://www.cisa.gov/known-exploited-vulnerabilities-catalog |
| EU AI Office / EU AI Act updates | Regulator | https://digital-strategy.ec.europa.eu/en/policies/ai-office |
| CNIL (data protection authority) | Regulator | https://www.cnil.fr/ |
| NVIDIA Product Security | Vendor | https://www.nvidia.com/en-us/security/ |
| Microsoft Security Response Center (MSRC) | Vendor | https://msrc.microsoft.com/ |
| GitHub Advisory Database | Vendor | https://github.com/advisories |
| OWASP Top 10 for LLM Applications | Community (AI) | https://genai.owasp.org/ |
| MITRE ATLAS (Adversarial Threat Landscape for AI Systems) | Community (AI) | https://atlas.mitre.org/ |
| Hugging Face security advisories | Vendor (AI) | https://huggingface.co/docs/hub/security |
| Python Safety DB / PyPI advisories | Community | https://github.com/pyupio/safety-db |
| OWASP | Community | https://owasp.org |
| SANS NewsBites | Newsletter | https://www.sans.org/newsletters/newsbites/ |
